Positional layers in transcriptomic data

An interactive version of the simulation behind Shared cis-regulation drives local gene co-expression across human tissues. Build a genome whose cis structure you choose, add a technical GC bias, then watch what each estimator reports. The point of the paper is that two of the three positional layers are not genome organisation at all — here you can switch them on and off.

The mean single-sample periodogram equals the landscape spectrum plus the covariance spectrum exactly. It is an algebraic identity, so the error should sit at machine precision whatever you choose above. If it does not, something is wrong with the code, not with the biology.

What this shows

Three things worth trying. Set the cis amplitude to zero and raise the GC bias: the naive estimator still reports a decay length of 10–20 genes, out of nothing. Set the GC bias to zero: the naive and corrected estimators agree, and both recover the truth. Lower the GC autocorrelation φ towards zero: the bias is still there but stops being positional, because the artefact inherits its range from the clustering of GC content, not from the bias itself.

Reference implementation: poslayers in this repository. The same calculation in Python is scripts/simulate_demo.py. Data and code availability, and the derivations, are in the paper.
